# SAB Monitor

ระบบตรวจคุณภาพข้อมูลภาคสนาม — โครงการติดตามและประเมินผลการส่งเสริมกิจกรรมทางกายในโรงเรียน
ตามยุทธศาสตร์ Specific Area-Based Health Promotion (สสส. / IPSR มหาวิทยาลัยมหิดล)

สร้างต่อยอดจากสถาปัตยกรรมของ SPA14 Monitor — ไฟล์เดียว ประมวลผลในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์

---

## การใช้งาน

1. เปิด `index.html` ในเบราว์เซอร์ (เปิดจากเครื่องโดยตรงได้ ไม่ต้องมีอินเทอร์เน็ต)
2. ลากไฟล์ผลสำรวจจาก LimeSurvey มาวาง — รองรับ `.csv` และ `.xlsx`
3. ระบบจับคู่คอลัมน์อัตโนมัติ แล้วแสดงผล 8 หน้า

**รูปแบบไฟล์ที่รองรับ:** ส่งออกจาก LimeSurvey แบบ **"แสดงคำตอบเต็ม"** (หัวคอลัมน์เป็นข้อความคำถาม ไม่ใช่รหัส) — ระบบตรวจจับบล็อกกิจกรรมทางกายจากรูปแบบหัวคอลัมน์ `N. ช่วง…` ที่ตามด้วย `มีสัปดาห์ละกี่วัน`

### แนวคิดหลักที่ต่างจาก SPA14

**หน้าต่างการแก้ไข (fix window)** — สำรวจครัวเรือนกลับไปแก้ยาก แต่โรงเรียนแก้ได้ทันทีถ้าทีมยังอยู่ในพื้นที่ ทุกสัญญาณจึงติดป้ายว่า

- `แก้ที่โรงเรียน` — ต้องปิดให้ได้ก่อนทีมออกจากพื้นที่วันนั้น
- `ตามกลับภายในสัปดาห์` — โทรหรือกลับไปโรงเรียนได้
- `แก้ที่สำนักงาน` — เป็นปัญหาของระบบหรือการทำความสะอาดข้อมูล

หน้า "เช็คก่อนออกจากโรงเรียน" กรองเฉพาะกลุ่มแรก จัดกลุ่มตามโรงเรียนและวันที่ พร้อมข้อความสั่งการรายบรรทัด

## ทะเบียนสัญญาณ

**ระดับเคส 71 สัญญาณ** — I (ทะเบียน) · P (กิจกรรมทางกาย) · S และ D (เรียนพิเศษ หน้าจอ งบเวลา) · X (ความพึงพอใจ) · Q (รูปแบบการตอบและ routing) · N (โซเดียม) · T (จังหวะการเก็บ)

**ระดับชุดข้อมูล 8 สัญญาณ (B1–B8)** — ความผิดปกติที่มองไม่เห็นจากเคสเดียว เช่น ข้อคำถามที่ถูกตอบ "ไม่มี" เกือบทั้งชุด หรือข้อความรู้ที่ทุกคนตอบเหมือนกัน

### แผงแจกแจงคำตอบ

นอกจากรายการสัญญาณ แต่ละหน้ายังแสดง **การกระจายคำตอบจริงรายข้อ** เพื่อให้เห็นภาพรวมของส่วนนั้นก่อนไล่ดูรายเคส ได้แก่ การกระจายของเรียนพิเศษและเวลาหน้าจอ · ตารางการเข้าร่วมและคะแนนความพึงพอใจข้อ 20 · ค่าเฉลี่ยรายข้อของมาตรวัดสิ่งแวดล้อม 9 ข้อ · และการกระจายคำตอบรายข้อของชุดโซเดียมทั้งสองช่วงอายุ

**ระดับผู้สัมภาษณ์ 4 สัญญาณ (Z2, Z3, Z4, Z6)** — เปรียบเทียบกับค่าเฉลี่ยทีม

กด **อภิธานศัพท์** มุมขวาบนเพื่อดูคำอธิบายทุกสัญญาณ หรือกดที่การ์ดสัญญาณในแต่ละหน้าเพื่อดู "หมายความว่าอะไร / ควรทำอย่างไร"

## การปรับเกณฑ์ (สำคัญ)

ค่าเริ่มต้นของ **เพดานนาทีรายข้อ** ตั้งจากโครงสร้างเวลาเรียนของโรงเรียนไทย ไม่ใช่จากข้อมูลจริงของพื้นที่

> **ต้องปรับหลัง pre-test** ที่ระยองก่อนใช้เก็บจริง

วิธีปรับ: ไปหน้า **ตรวจระดับชุดข้อมูล** → ตารางสรุปรายข้อ ดูคอลัมน์ "นาที มัธยฐาน" และ "ต่ำสุด–สูงสุด" → ถ้าข้อไหนมีเคสเกินเพดานจำนวนมากทั้งที่ดูสมเหตุผล ให้ขยายเพดานในหน้า **เกณฑ์การตรวจ** แล้วกด "คำนวณใหม่"

ค่าที่แก้อยู่ในหน่วยความจำเท่านั้น ไม่ถูกบันทึกถาวร — ถ้าได้ค่าที่ลงตัวแล้ว ให้แก้ค่าเริ่มต้นในบล็อก `PA_ITEMS` และ `MISC` ที่ต้นไฟล์ `index.html`

## ข้อจำกัดของไฟล์ส่งออกปัจจุบัน

เงื่อนไขต่อไปนี้ออกแบบไว้แล้วแต่ยังทำงานไม่ได้ เพราะไฟล์ไม่มีข้อมูลรองรับ (ดูรายละเอียดในหน้าอัปโหลด)

| ฟิลด์ที่ขาด | ผลกระทบ |
|---|---|
| `startdate` | คำนวณระยะเวลาสัมภาษณ์ไม่ได้ — ระบบใช้ "ระยะห่างระหว่างเคสของผู้สัมภาษณ์คนเดียวกัน" แทนไปก่อน |
| ความยินยอมผู้ปกครอง / assent | ตรวจความครบถ้วนด้านจริยธรรมไม่ได้ |
| รหัสประจำตัววิจัย | เชื่อมทะเบียนนักเรียนและ match รอบ Midline/Endline ไม่ได้ |
| รหัสโรงเรียน / ห้องเรียน | เทียบกับทะเบียน 65 โรงไม่ได้ |
| ทะเบียนเป้าหมายรายโรงเรียน | คำนวณความครอบคลุมของการเก็บแบบสำมะโนไม่ได้ (สัญญาณ R1–R5) |
| ส่วนการนอนหลับ J01–J02 | ไม่พบในไฟล์ส่งออก |
| สถานะเคส (สำเร็จ/ปฏิเสธ/ไม่พบตัว) | คำนวณอัตราการตอบและอัตราปฏิเสธไม่ได้ |

## ความปลอดภัยของข้อมูล (PDPA)

- ประมวลผลทั้งหมดในเบราว์เซอร์ ไม่มีการส่งข้อมูลออก ไม่มีเซิร์ฟเวอร์ ไม่มีฐานข้อมูล
- ปิดหน้าเว็บ = ข้อมูลหายจากหน่วยความจำทันที
- ไฟล์ `index.html` ไม่มีข้อมูลผู้ตอบฝังอยู่ จึงเผยแพร่เป็น public repo ได้
- **ข้อควรระวัง:** ไฟล์ส่งออกมีชื่อ–สกุลจริงของนักเรียน ห้ามอัปโหลดไฟล์ข้อมูลเข้า repository

## Deploy ขึ้น GitHub Pages

```bash
git init
git add .
git status          # ← ตรวจว่าไม่มีไฟล์ .csv หรือ .xlsx โผล่ในรายการ
git commit -m "SAB Monitor v1.1"
git branch -M main
git remote add origin https://github.com/<username>/sab-monitor.git
git push -u origin main
```

จากนั้นไปที่ **Settings → Pages** แล้วตั้ง Source เป็น GitHub Actions (workflow ใน `.github/workflows/deploy.yml` จะ deploy ให้อัตโนมัติทุกครั้งที่ push เข้า `main`)

อัปเดตเวอร์ชัน: แทนที่ `index.html` แล้ว push — ถ้ายังเห็นของเก่าให้กด `Ctrl+Shift+R` เพื่อล้างแคช

## ไฟล์ในรีโพนี้

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | ตัวระบบทั้งหมด ไฟล์เดียวจบ ไม่มีขั้นตอน build |
| `README.md` | คู่มือผู้ใช้ |
| `CONTRIBUTING.md` | คู่มือสำหรับผู้ดูแลและแก้ไขระบบต่อ |
| `CHANGELOG.md` | บันทึกการเปลี่ยนแปลงและเหตุผลของการปรับเกณฑ์ |
| `.gitignore` | บล็อกไฟล์ข้อมูลผู้ตอบไม่ให้หลุดเข้ารีโพ |
| `.gitattributes` | บังคับ LF และไม่นับ `index.html` เป็นโค้ดของโครงการ |
| `.nojekyll` | ปิดการประมวลผลด้วย Jekyll บน GitHub Pages |
| `.github/workflows/deploy.yml` | deploy อัตโนมัติเมื่อ push |
